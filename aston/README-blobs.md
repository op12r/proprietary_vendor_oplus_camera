# aston blobs

`blobs/` is generated by `extract-files.py` from stock CPH2585_11.A.01 and committed.
The patched `blobs/proprietary/system_ext/priv-app/OplusCamera/OplusCamera.apk` is 165 MB,
over GitHub's 100 MB file limit, so it is stored with Git LFS.

Install git-lfs before syncing (`repo init ... --git-lfs`, or `git lfs pull` in this repo).
Without it the APK is a small pointer file and the build fails.

To regenerate everything instead, run `extract-files.py --allow-prohibited-files <dump>`
against the stock files (all 20 patch checks must pass).
