# aston blobs

`blobs/` is generated by `extract-files.py` from stock CPH2585_11.A.01 and committed,
except `blobs/proprietary/system_ext/priv-app/OplusCamera/OplusCamera.apk`: the patched
APK is 165 MB, over GitHub's 100 MB file limit.

Before a build, put the patched APK in place by either:

- copying the prebuilt patched OplusCamera.apk you were given to that path, or
- running `extract-files.py --allow-prohibited-files <dump>` against the stock files, which
  regenerates every blob (all 20 patch checks must pass).
